# 밸런싱 로봇 제작 로드맵

## 전체 흐름

```
[1단계] 개발환경 설정
    ↓
[2단계] 하드웨어 조립
    ↓
[3단계] 배선
    ↓
[4단계] 펌웨어 - MPU6050 통신 확인
    ↓
[5단계] 펌웨어 - 각도 계산
    ↓
[6단계] 펌웨어 - 모터 제어
    ↓
[7단계] 펌웨어 - PID 제어 통합
    ↓
[8단계] 튜닝 (PID 파라미터 조정)
    ↓
[완성]
```

---

## 1단계: 개발환경 설정

**목표:** STM32 코드를 작성하고 업로드할 수 있는 환경 구축

- [ ] STM32CubeIDE 설치 (무료, ST 공식)
- [ ] ST-LINK V2 USB 드라이버 설치
- [ ] STM32CubeIDE에서 STM32F103C8T6 신규 프로젝트 생성
- [ ] ST-LINK로 보드 연결 후 빈 코드 업로드 테스트 (LED 깜빡이기)

**확인 기준:** Blue Pill 보드의 PC13 LED가 깜빡이면 성공

---

## 2단계: 하드웨어 조립

**목표:** 로봇 프레임 완성

순서:
1. N20 모터에 바퀴+브라켓 결합
2. M3 서포트(35mm)로 상판/하판 2층 프레임 구성
   - 하판: 배터리 홀더 + LM2596 컨버터
   - 상판: STM32 보드 + TB6612FNG + 브레드보드
3. MPU-6050은 로봇 무게중심 근처에 수직으로 고정
4. HC-06은 상판 측면에 고정

**주의:** MPU-6050 장착 방향이 나중에 축 설정에 영향을 미침
- 센서의 X축 or Y축이 로봇의 앞뒤 기울기 방향과 일치하도록 장착

---

## 3단계: 배선

**목표:** 모든 부품을 올바르게 연결

### 전원 배선
```
18650 x2 (직렬, 7.4V)
    ├── TB6612FNG VM 핀 → 모터 전원 (7.4V)
    └── LM2596 입력 → 출력 5V 조정
            └── STM32 5V 핀 → 보드 전원
                    └── STM32 3.3V 핀 → TB6612FNG VCC, MPU6050 VCC, HC-06 VCC
```

### STM32 핀 배선
| STM32 핀 | 연결 대상 | 용도 |
|---|---|---|
| PB6 (SCL) | MPU-6050 SCL | I2C 클럭 |
| PB7 (SDA) | MPU-6050 SDA | I2C 데이터 |
| PA0 (TIM2_CH1) | TB6612FNG PWMA | 모터A PWM |
| PA1 (TIM2_CH2) | TB6612FNG PWMB | 모터B PWM |
| PB0 | TB6612FNG AIN1 | 모터A 방향 |
| PB1 | TB6612FNG AIN2 | 모터A 방향 |
| PB10 | TB6612FNG BIN1 | 모터B 방향 |
| PB11 | TB6612FNG BIN2 | 모터B 방향 |
| PB12 | TB6612FNG STBY | 드라이버 활성화 |
| PA9 (TX) | HC-06 RX | 블루투스 송신 |
| PA10 (RX) | HC-06 TX | 블루투스 수신 |
| GND | 모든 부품 GND | 공통 GND |

**확인 기준:** 배선 후 멀티미터로 단락(쇼트) 없음 확인, 전원 인가 시 STM32 전원 LED 점등

---

## 4단계: 펌웨어 - MPU6050 통신 확인

**목표:** I2C로 MPU-6050에서 데이터를 읽을 수 있음을 확인

STM32CubeIDE에서 설정:
- I2C1 활성화 (PB6=SCL, PB7=SDA)
- USART1 활성화 (PA9=TX, PA10=RX, 9600bps) → 시리얼 모니터용

작성할 코드:
- MPU-6050 초기화 (레지스터 설정)
- 가속도/자이로 raw 값 읽기
- USART1로 값 출력

**확인 기준:** 시리얼 터미널(또는 HC-06 앱)에서 숫자가 출력되고, 센서를 기울이면 값이 변함

---

## 5단계: 펌웨어 - 각도 계산

**목표:** 신뢰할 수 있는 기울기 각도(degree) 계산

구현할 내용:
- 가속도계로 정적 각도 계산: `angle = atan2(ay, az) * 180 / PI`
- 자이로로 동적 각도 계산: `angle += gyro_x * dt`
- **상보 필터** 적용 (두 값을 융합):
  ```
  angle = 0.98 * (angle + gyro * dt) + 0.02 * accel_angle
  ```

**확인 기준:** 로봇을 손으로 기울이면 각도 값이 안정적으로 따라옴 (노이즈가 적고 드리프트 없음)

---

## 6단계: 펌웨어 - 모터 제어

**목표:** TB6612FNG를 통해 모터 속도와 방향 제어

STM32CubeIDE에서 설정:
- TIM2 CH1, CH2 PWM 출력 활성화 (PA0, PA1)
- PWM 주파수 1kHz, 듀티비 0~1000 범위

작성할 코드:
- 모터 속도 함수: `Motor_SetSpeed(int speedA, int speedB)`
- 양수 → 전진 방향, 음수 → 후진 방향
- 데드밴드 처리 (너무 작은 값은 0으로)

**확인 기준:** 코드로 모터 속도/방향을 바꿀 수 있음

---

## 7단계: 펌웨어 - PID 제어 통합

**목표:** 각도를 읽어 모터를 제어하는 PID 루프 완성

PID 구조:
```
목표각도(0도) - 현재각도 = 오차
    → P항: 오차 × Kp
    → I항: 오차 누적 × Ki
    → D항: 오차 변화율 × Kd
    → 합산 → 모터 출력
```

초기 PID 값 (조정 필요):
- Kp = 25.0
- Ki = 0.0
- Kd = 0.8
- setpoint = 0.0 (목표 각도, 나중에 미세 조정)

안전 장치:
- 각도가 ±45도 초과 시 모터 정지 (쓰러진 상태)
- 적분 누적 상한 설정 (windup 방지)

**확인 기준:** 손으로 잡고 기울이면 모터가 반응함

---

## 8단계: PID 튜닝

**목표:** 로봇이 실제로 균형을 유지함

튜닝 방법:
1. **Kp만 올리기** → 모터가 반응하지만 진동 발생
2. **Kd 올리기** → 진동 감소, 안정화
3. **Ki 조금 추가** → 미세한 기울기 보정
4. **setpoint 조정** → 로봇이 제자리에 서도록 오프셋 조정

HC-06 블루투스 활용:
- 스마트폰 앱(Serial Bluetooth Terminal 등)으로 파라미터 실시간 전송
- 명령 예시: `P25.0`, `I0.5`, `D1.2`, `S0.3`

**확인 기준:** 손을 놓아도 수 초 이상 균형 유지
